¿QUÉ SE HIZO?
─────────────
  1. Unificación de entradas (STR + Tickex) en una sola tabla
  2. Nuevo módulo para registrar ingresos manuales
  3. AJAX para agregar/eliminar ingresos sin recargar
  4. Mantiene estructura visual y permisos existentes

  inc/manual_income.php   ← Gestión de ingresos

API:

CÓMO FUNCIONA
──────────────

1. UNIFICACIÓN DE ENTRADAS
   
   panel_evento.php
   └─ get_unified_entries(pdo, evento_id, filters)
      ├─ SELECT FROM entradas (STR)
      ├─ SELECT FROM v_senforms_bridge_status OR senforms_bridge_tickets
      ├─ Normaliza a formato común
      └─ Retorna array unificado

2. INGRESOS MANUALES
   
   Agregar:
   └─ Formulario → add_manual_income.php → BD
   
   Eliminar:
   └─ Botón 🗑 → delete_manual_income.php → BD

TABLA DE DATOS (unificada)
───────────────────────────

Campos que visualiza:
  • Origen      → STR o TICKEX
  • ID          → ticket_id
  • Nombre      → nombre
  • Email       → email
  • Tipo        → tipo (VIP, General, etc)
  • Código/Ref  → ticket_ref
  • Pago        → is_paid (✓ o ✗)
  • Estado      → is_checked_in (OK o Pendiente)
  • Acciones    → Link a ticket (STR) o texto (TICKEX)

═══════════════════════════════════════════════════════════════════════════════

BASE DE DATOS
──────────────

Tabla nueva (creada automáticamente):
  manual_income
  ├─ id (PK)
  ├─ evento_id (FK)
  ├─ concepto (qué es el ingreso)
  ├─ monto (cantidad en dinero)
  ├─ descripcion (notas adicionales)
  ├─ creado_por (user_id de quien lo agregó)
  ├─ created_at (timestamp automático)
  └─ updated_at (timestamp automático)

Índice:
  idx_manual_income_evento (para queries rápidas)

JAVASCRIPT (AJAX)
──────────────────

Agregar ingreso:
  form#formManualIncome
  └─ submit → fetch('/add_manual_income.php')
     ├─ POST con FormData
     └─ Reload en éxito

Eliminar ingreso:
  button.btn-delete-income
  └─ click → fetch('/delete_manual_income.php')
     ├─ POST con income ID
     └─ Reload en éxito

FUNCIONES PRINCIPALES
───────────────────────

En inc/unified_tickets.php:

  get_unified_entries(pdo, evento_id, filters)
  └─ NÚCLEO: retorna entradas unificadas
  └─ Entrada: (pdo, id evento, filtros)
  └─ Salida: array [source, ticket_id, nombre, email, is_paid, ...]

  count_unified_entries(entries)
  └─ Calcula stats
  └─ Entrada: array de entradas
  └─ Salida: [total, checkins, paid, pendiente]

En inc/manual_income.php:

  add_manual_income(pdo, evento_id, concepto, monto, descripcion)
  └─ Agrega ingreso
  └─ Retorna: true/false

  delete_manual_income(pdo, income_id)
  └─ Elimina ingreso
  └─ Retorna: true/false

  get_manual_incomes(pdo, evento_id)
  └─ Lista ingresos del evento
  └─ Retorna: array de filas

  get_total_manual_income(pdo, evento_id)
  └─ Suma total
  └─ Retorna: float
